一般運動記錄保存在使用者瀏覽器。手動繳交摘要時，伺服器保存課堂代號、開始時間、運動時間、距離及有效 GPS 點數，不接收身體資料或完整 GPS 軌跡。學生也可另外授權將運動感受及最多 200 字的路線／GPS 觀察交給任課教師；未授權時反思不會提交。熱量估算只在裝置上依使用者選填的體重計算。即時同步是另一項選擇；勾選後會分享本次軌跡與運動數值，僅本人及該班級教師可查看。

即時同步保存什麼

  • 即時紀錄索引：班級、課程、運動者代號、開始／結束時間、狀態與到期時間。
  • 即時定位點：經緯度、時間、accuracy 與分段編號；步數、步頻、時間及距離定期更新。
  • 不把 Access 登入 token 或 email 寫入即時軌跡資料。帳號身分只用於伺服器端權限判斷。
  • 運動結束後 24 小時自動清除點位及即時紀錄；運動者本人或班級教師也能提前刪除。

該班教師查看班級學生勾選分享的即時軌跡；管理該班課程與成員。不能查看其他教師班級。
其他已登入者查看自己的資料。沒有班級關係時，API 會拒絕讀取軌跡。

Cloudflare Access 管理登入；教師身份由 Worker secret `TEACHER_EMAILS` 指定，並且必須是該班級建立者。登入與班級歸屬均由 API 驗證。只部署在 GitHub Pages 時，班級雲端與即時同步 API 不可用，本機運動紀錄仍可使用。

班級摘要資料

Cloudflare D1 保存班級、成員、課程及摘要繳交。每人每堂課最多繳交一筆摘要；反思另有獨立授權，授權後會隨摘要保留至刪除。課程可設定班級共同分鐘目標，畫面只彙總全班已繳交的運動時間，不列個人排名。移除成員或刪除班級時，相關摘要與反思會刪除。伺服器不保存身高、體重、年齡、MET 或熱量。班級摘要目前沒有自動到期時間，教師需依課堂事先告知的期限匯出備份並刪除不再需要的資料。學生刪除雲端繳交不會刪除自己裝置上的紀錄。

使用前告知

  • 說明為何需要提交摘要或分享即時軌跡，提供不同意即時分享時的替代方式。
  • 避免在代號中輸入姓名、學號或其他不必要的識別資訊。
  • 教師避免公開班級加入碼及即時儀表板網址。
  • 定位受手機、瀏覽器權限、省電設定、網路與環境影響；頁面不保證固定 GPS 更新頻率，也不作自動出席或防作弊判定。
